# お試しコース申込フォーム → スプレッドシート別タブ 設定手順

お試しコース（`pages/news-otameshi/`）の申込フォームを、
**既存の予約スプレッドシートと同じファイル内の別タブ「お試しコース申込」**に記録します。
通知メール（管理者）と自動返信メール（申込者）も送信します。

## 仕組み
- フロントは `action=otameshi` で既存GAS（予約と同じURL）にPOSTします。
- GAS側で `action=otameshi` を判定し、
  - `SHEET_ID`（予約と同じスプレッドシート）内のタブ **「お試しコース申込」** に追記（無ければ自動作成）
  - 管理者 `NOTIFY_EMAIL` へ通知
  - 申込者へ自動返信
- 予約・問い合わせ・無料診断のタブとは**完全に別タブ**なので混ざりません。

## 反映手順（運営者の作業・1回だけ）
1. Google Apps Script のプロジェクト（現在 `BOOKING_GAS_URL` を発行しているもの）を開く。
2. `docs/booking_calendar_gas.gs` の最新内容で**コード全体を差し替え**る
   （追加点：`doPost` の `action==='otameshi'` 分岐と、
   `saveOtameshiToSheet` / `sendOtameshiNotification` / `sendOtameshiThankYou` の3関数）。
3. **デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン「新バージョン」→ デプロイ**。
   ※ **URLは変わりません**（同じデプロイを更新するため）。フロント側の変更は不要です。
4. テスト送信して、スプレッドシートに **「お試しコース申込」タブが自動生成**され、
   行が追記されること・通知/自動返信メールが届くことを確認。

| タイムスタンプ | 送信元 | お名前 | フリガナ | メールアドレス | 電話番号 | 学年 | 志望大学 | 体験希望科目 | ご相談内容 |

## 別ファイル（別スプレッドシート）に分けたい場合
`saveOtameshiToSheet` 冒頭の `SpreadsheetApp.openById(SHEET_ID)` を、
新しいスプレッドシートIDに変えるだけでOK（例：`var OTAMESHI_SHEET_ID = '...';` を定義して使用）。
