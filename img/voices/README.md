# img/voices/ — 合格者の声・保護者アンケート画像の置き場

ここに画像ファイルを置き、`assets/js/voices-data.js`（単一データソース）でパスを指定すると、
ホーム／合格者の声ページ（`pages/voices.html`）に自動で反映されます。

- パスは**サイトルート相対**で書きます（例: `img/voices/case01.jpg`）。
  → `/`（トップ）からでも `/pages/`（下層）からでも、自動でパス解決されます。
- 画像が無い／パス未設定のときは**自動で非表示**（空枠は残りません）。
- 画像の読み込みに失敗した場合も、その画像だけ自動で非表示になります。

---

## ① 各「合格者の声」カードに画像を出す（保護者アンケートのスキャン等）

`assets/js/voices-data.js` の対象ケースの `image` を設定します:

```js
{
  id: 'case01', ...
  image: 'img/voices/case01.jpg',   // ← ここにパスを書くだけ
  ...
}
```

→ `pages/voices.html` の **CASE 01 のカード内**に画像が表示されます。

推奨ファイル名: `case01.jpg` 〜 `case13.jpg`（ケース番号に対応）。

## ② 保護者アンケートのグリッド（ホーム＆合格者の声ページ）

`assets/js/voices-data.js` の `SURVEY_IMAGES` 配列に追加します:

```js
var SURVEY_IMAGES = [
  { src: 'img/voices/survey-01.jpg', alt: '保護者アンケート（東京大学 合格）' },
  { src: 'img/voices/survey-02.jpg', alt: '保護者アンケート（医学部 合格）' },
];
```

→ ホームの「合格者の声」セクションと、`pages/voices.html` の「保護者アンケート」見出しに
グリッド表示されます（1件以上で自動表示／0件なら非表示）。

---

## 推奨仕様
- 形式: JPG / PNG / WebP
- サイズ: 横 800〜1200px 程度、1ファイル数百KB以内を目安
- 個人情報（氏名・顔写真・手書き内容など）の掲載は、ご本人・保護者様の**許可範囲**をご確認ください。
